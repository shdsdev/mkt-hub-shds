# Companion Added Confirmation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show an explicit success modal with the new companion's name and generated folio after either administrative add-companion flow succeeds.

**Architecture:** Keep both existing server actions and their authorization/mutation behavior. Extend their serializable success state with the generated attendee identity, add one shared client dialog component using the existing Base UI dialog primitive, and let each existing form own only its open/data state.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Base UI dialog, existing Tailwind/shadcn visual system, Vitest.

## Global Constraints

- Apply the confirmation to the internal Administration form and the Registrations table `Agregar acompañante` modal.
- Use the same `backupCode` generated by `addAttendeeToRegistration`; never generate a second code in the browser.
- Keep the existing capacity bypass, email uniqueness, authorization, audit, email, webhook, and revalidation behavior unchanged.
- Errors remain inline and never open the success modal.
- The modal title is `Acompañante agregado exitosamente` and its only action is `Listo`.
- Do not modify the public registration form or unrelated dirty worktree changes.
- Do not commit or push until explicitly requested.

- [ ] **Step 2: Implement the shared dialog with the existing primitive**

Use the existing dialog pattern and keep the success copy explicit:

```tsx
"use client";

import { Dialog as DialogPrimitive } from "@base-ui/react/dialog";
import { Button } from "@/components/ui/button";

export function CompanionAddedDialog({
  open,
  onOpenChange,
  companion,
}: {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  companion: { fullName: string; backupCode: string } | null;
}) {
  if (!companion) return null;

  return (
    <DialogPrimitive.Root open={open} onOpenChange={onOpenChange}>
      {open ? (
        <DialogPrimitive.Portal>
          <DialogPrimitive.Backdrop className="fixed inset-0 z-50 bg-black/60" />
          <DialogPrimitive.Popup className="fixed inset-0 z-50 m-auto h-fit w-[calc(100%-2rem)] max-w-md rounded-xl border border-emerald-500/40 bg-popover p-6 text-popover-foreground shadow-2xl">
            <div className="rounded-lg border border-emerald-500/40 bg-emerald-500/10 px-3 py-2 text-sm font-medium text-emerald-200" role="status">
              Acompañante agregado exitosamente
            </div>
            <DialogPrimitive.Title className="mt-4 text-base font-semibold">{companion.fullName}</DialogPrimitive.Title>
            <p className="mt-1 text-sm text-muted-foreground">Guardá este folio para identificar su acceso.</p>
            <p className="mt-4 select-all rounded-lg border border-border bg-background px-4 py-3 text-center font-mono text-xl font-semibold tracking-[0.18em]">
              {companion.backupCode}
            </p>
            <Button className="mt-5 w-full" onClick={() => onOpenChange(false)}>Listo</Button>
          </DialogPrimitive.Popup>
        </DialogPrimitive.Portal>
      ) : null}
    </DialogPrimitive.Root>
  );
}
```
