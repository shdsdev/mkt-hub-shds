# Telegram Message Templates Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add global and event-specific Telegram message templates with safe server-side tag replacement.

**Architecture:** Store the global template in `telegram_settings` and the event override in `events`. A pure notification renderer resolves event → organization → default templates, replaces a fixed tag catalog, and builds a Telegram-safe message.

**Tech Stack:** Next.js 16, React 19 server actions, Drizzle/PostgreSQL, Zod, Vitest, Tailwind CSS.

## Global Constraints

- Never persist or render `TELEGRAM_BOT_TOKEN`.
- Use plain text templates; no arbitrary HTML, Markdown, or code execution.
- Event template overrides global template; empty values fall back.
- Keep localhost review URLs out of Telegram inline buttons.
- Preserve current fire-and-forget notification behavior.
